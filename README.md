## 🎯 Objetivo do Sistema
Este projeto é um script desenvolvido em Python para uma campanha de conscientização ambiental de uma companhia de saneamento. O programa coleta o tipo de imóvel e o consumo mensal de água em metros cúbicos ($m^3$) e classifica o perfil do usuário, emitindo alertas educativos para incentivar a economia de água e identificar possíveis vazamentos.

## ⚙️ Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Versionamento:** Git e GitHub
